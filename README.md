# MediKana-Templates

Frontend-шаблоны для медицинского сайта «Медикана».

Проект содержит готовые страницы и компоненты интерфейса (HTML/CSS/Vanilla JS): каталог анализов, детальные страницы, список врачей, страницы филиалов/контактов, акции, выезд на дом и т.д.

## Возможности

- Каталог анализов с фильтрацией и динамической отрисовкой карточек
- Детальная страница анализа с вкладками (Описание / Состав комплекса / Подготовка)
- Страницы врачей и запись/формы
- Страница филиалов (центров) и контакты
- Акции, выезд на дом, главная страница
- Локальные данные в `assets/data/*.json`

## Структура проекта

- `index.html` — главная
- `catalog.html` — каталог анализов
- `analysis-detail.html` — детальная страница анализа
- `doctors.html` — врачи/запись
- `centers.html` — филиалы
- `contacts.html` — контакты
- `promotions.html` — акции
- `home-visit.html` — выезд на дом

Папки:

- `assets/css/` — стили
- `assets/js/` — JavaScript-логика
- `assets/data/` — мок-данные (JSON)
- `assets/images/` — изображения/SVG

## Запуск

### Быстрый способ

Открой любой `.html` файл в браузере.

### Рекомендуемый способ (локальный сервер)

Чтобы избежать ограничений `file://` и корректно тестировать `fetch`, запускай через простой HTTP сервер.

Например (если установлен Python):

```bash
python3 -m http.server 8080
```

После этого открой:

- `http://localhost:8080/index.html`

## Примечания

- Данные берутся из `assets/data/*.json`.
- В проекте используется Vanilla JS без сборщиков и фреймворков.
